# Implementation Plan: Interactive Diff Toggle

**Track ID:** interactive-diff_20260226
**Spec:** [spec.md](./spec.md)
**Created:** 2026-02-26
**Status:** [ ] Not Started

## Overview

Extend tf's plan/apply output pipeline to capture full resource diff blocks
alongside their collapsed summaries. After output completes, launch a lightweight
interactive viewer that lets the user navigate and toggle individual blocks
open/closed with keyboard shortcuts.

## Phase 1: Block Capture

Extend the output filter so that each collapsed summary retains the original
full diff body in memory, enabling the TUI to re-display it on demand.

### Tasks

- [x] Task 1.1: Define a `ResourceBlock` struct holding `summary` (string) and
      `body` ([]string of original lines).
- [x] Task 1.2: Refactor the output filtering logic to populate `ResourceBlock`
      slices instead of only printing collapsed summaries.
- [x] Task 1.3: Write unit tests covering block parsing for add, change, destroy,
      and replace operations.

### Verification

- [ ] `make check` passes; block capture tests pass for all resource change types.

## Phase 2: Interactive Viewer

Implement the keyboard-driven TUI that renders the list of `ResourceBlock`s with
expand/collapse state.

### Tasks

- [x] Task 2.1: Implement a `Viewer` type with a list of blocks, a cursor index,
      and per-block expanded/collapsed state.
- [x] Task 2.2: Implement the render loop: draw collapsed summaries with a cursor
      indicator; draw full body lines for expanded blocks.
- [x] Task 2.3: Implement keyboard input handling — arrow keys / j/k to move
      cursor, Enter/Space to toggle expand/collapse, q/Ctrl-C to quit.
- [x] Task 2.4: Write unit tests for viewer state transitions (navigate, expand,
      collapse, exit).

### Verification

- [ ] `make check` passes; viewer state tests cover all navigation and toggle paths.

## Phase 3: Integration

Wire the captured blocks and interactive viewer into the existing tf plan/apply
execution path.

### Tasks
