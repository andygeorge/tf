# Specification: Interactive Diff Toggle

**Track ID:** interactive-diff_20260226
**Type:** Feature
**Created:** 2026-02-26
**Status:** Draft

## Summary

Allow collapsed resource diff blocks in `tf plan`/`apply` output to be expanded
and collapsed interactively via keyboard, so engineers can inspect details without
re-running the command.

## Context

`tf` collapses verbose terraform resource change blocks to single-line summaries.
While this reduces noise, users sometimes need to drill into the full diff for a
specific resource. Currently they must re-run the command to see the full output.

## User Story

As a tf user, I want to expand a collapsed diff inline so that I can inspect
resource details without re-running plan/apply.

## Acceptance Criteria

- [ ] During (or after) `tf plan`/`tf apply`, resource diff blocks are displayed
      as collapsed single-line summaries by default.
- [ ] The user can navigate between collapsed entries using keyboard shortcuts
      (e.g., arrow keys or j/k).
- [ ] Pressing a key (e.g., Enter or Space) expands the selected entry to show
      the full diff block.
- [ ] Pressing the same key again collapses the entry back to its summary line.
- [ ] The interactive view exits cleanly and returns the user to their shell.

## Dependencies

None — builds on existing output filtering logic.

## Out of Scope

- Changes to non-plan/apply commands (`tf target`, `tf ver`, passthrough)
- Mouse support
- Persistent state or config file changes
- Color/theming changes

## Technical Notes

No specific approach mandated. Options include bubbletea, tcell, or raw ANSI/stdin.
Keep the zero-external-dependency spirit in mind when choosing.
